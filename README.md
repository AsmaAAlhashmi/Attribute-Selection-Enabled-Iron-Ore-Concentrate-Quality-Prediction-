
TITLE : Interpretable Artificial Intelligence with Attribute Selection Enabled Iron Ore Concentrate Quality Prediction for Froth Flotation Mining Process


JOURNAL NAME :  The visual computer

## 📁 Dataset

### 1. Overview
The dataset used in this study is the **“Quality Prediction in a Mining Process”** dataset, which contains real-time industrial data collected from a flotation plant.

The objective of the dataset is to predict the quality of iron ore concentrate by estimating impurity levels, particularly the percentage of silica (% Silica) in the final output.

---

### 2. Data Source

- **Dataset Name:** Quality Prediction in a Mining Process  
- **Platform:** Kaggle  
- **Link:** https://www.kaggle.com/datasets/edumagalhaes/quality-prediction-in-a-mining-process  

This dataset contains operational and chemical measurements from a real mineral processing plant.

---

### 3. Dataset Characteristics

- **Total Attributes:** 24  
- **Selected Features:** 23 input features  
- **Target Variables:**
  - % Silica Concentrate (primary prediction target)
  - % Iron Concentrate (secondary quality indicator)

- **Data Type:** Multivariate time-series (tabular)

---

### 4. Feature Description

The dataset includes process-related variables such as:

| Feature Category | Description |
|-----------------|------------|
| Air Flow | Air input to flotation columns |
| Pulp Levels | Material levels inside flotation cells |
| pH Levels | Chemical acidity/alkalinity |
| Reagent Flow | Chemical inputs (e.g., amina flow) |
| Feed Composition | % Iron feed, % Silica feed |
| Froth Level | Surface behavior during flotation |

These variables directly influence the efficiency of mineral separation.

---

### 5. Target Variable

- **Primary Target:** % Silica Concentrate  
  - Represents impurity level in iron ore  
  - Lower values indicate better quality

- **Secondary Target:** % Iron Concentrate  
  - Represents recovery efficiency
